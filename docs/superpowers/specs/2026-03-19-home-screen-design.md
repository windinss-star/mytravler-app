# 홈 화면 디자인 스펙

## 목적

앱의 첫 진입 화면인 홈을 토스형으로 깔끔하게 재구성한다. 홈은 빠르게 이해되고 즉시 탐색 가능한 구조를 목표로 하며, 여행 서비스의 핵심 진입점을 단순한 2x2 메뉴로 제공한다.

## 핵심 방향

- 전체 톤은 밝고 단정한 토스형 서비스 화면으로 구성한다.
- 지도 화면만 다크 톤을 유지하고, 홈은 밝은 배경과 정돈된 카드 구조를 사용한다.
- TDS 성격에 맞게 과한 장식보다 정보 구조, 여백, 명확한 계층을 우선한다.
- 메뉴 카드는 작은 3D 아이콘으로 시각적 이해를 돕되, 아이콘은 보조 역할에 머문다.

## 레이아웃

### 1. 상단 헤더

- 좌측에 서비스명 `마이트래블`을 표시한다.
- 헤더는 높이를 과하게 키우지 않고 가볍고 단정하게 유지한다.
- 우측 액션은 초기 버전에서 비워두거나 최소화한다.

### 2. 검색 영역

- 헤더 바로 아래에 넓은 검색창을 배치한다.
- 플레이스홀더는 `나라, 도시, 유튜버, 코스를 검색해보세요`를 기본안으로 사용한다.
- 검색창은 둥근 모서리, 밝은 배경, 얇은 경계선 기반의 토스형 입력 필드로 구성한다.

### 3. 메인 메뉴 영역

- 검색창 아래에 `2 x 2` 정사각형 카드 그리드를 배치한다.
- 각 카드는 동일한 비율과 간격을 유지한다.
- 카드 내부는 위쪽에 작은 3D 아이콘, 아래에 메뉴명을 배치한다.

메뉴 구성:

- 국가 탐색
- 유튜버 탐색
- 인기 나라 보기
- 인기 코스 보기

### 4. 하단 GNB

- `홈 / 국가 / 유튜버 / 마이`를 하단 GNB로 이동한다.
- 현재 선택 상태는 `홈`이 강조된다.
- 전체 스타일은 심플하고 직관적인 아이콘+텍스트 탭 구조를 사용한다.

## 시각 스타일

- 배경은 흰색 또는 아주 옅은 회색 계열을 사용한다.
- 카드와 입력창은 흰색 바탕, 둥근 모서리, 약한 그림자 또는 얇은 라인으로 처리한다.
- 본문 텍스트는 진한 회색, 보조 텍스트는 중간 회색을 사용한다.
- 홈에서는 과한 다크 배경, 강한 그래디언트, 무거운 질감 표현을 사용하지 않는다.

## 3D 아이콘 원칙

- 아이콘은 토스처럼 밝고 부드러운 미니 오브젝트형으로 구성한다.
- 과장된 장난감 스타일이나 강한 광택은 피한다.
- 작은 크기에서도 메뉴 의미가 전달되도록 단순한 형태를 우선한다.

메뉴별 아이콘 방향:

- 국가 탐색: 지구본, 지도 핀, 대륙 실루엣 계열
- 유튜버 탐색: 프로필 배지, 카메라, 채널 성격의 오브젝트
- 인기 나라 보기: 깃발, 별, 트로피 계열
- 인기 코스 보기: 루트 라인, 나침반, 경로 카드 계열

## TDS 반영 원칙

- 사용자에게 빠르게 이해되는 정보 구조를 우선한다.
- 컴포넌트 간 간격과 정렬 규칙을 일관되게 유지한다.
- 아이콘은 텍스트를 보조하는 수단으로 사용하고, 텍스트 이해를 방해하지 않게 한다.
- 홈 화면은 탐색 허브 역할에 집중하고, 세부 정보는 각 상세 화면으로 위임한다.

## 구현 범위

이번 변경 범위는 홈 화면에 한정한다.

- 헤더 구조 변경
- 검색창 추가
- 2x2 메뉴 카드 UI 추가
- 하단 GNB 구조 반영

이번 단계에서 제외:

- 실제 검색 로직 고도화
- 홈에서 추가 추천 섹션 확장
- 지도 화면 자체의 스타일 변경
